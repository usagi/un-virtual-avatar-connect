配信の支度をまとめる

配信モードに切り替えたらOBS・U.N. Avatar・U.N. Motionを起動。モードごとに連携アプリの起動・終了を登録できます。

モードと連携アプリの使い方

初回起動

  1. ZIPをすべて展開

    展開したフォルダーの virtual-avatar-connect-desktop.exe を起動します。

  2. 用途を選んで作成

    通知とクリップ紹介なら「Twitch配信支援（AIなし）」を選び、「作成して開始」へ。AI契約やアバターの準備は不要です。

  3. 使う機能を接続

    Twitchでは配信者名を設定し、チャットへ投稿するアカウントを選んで認証します。配信者と同じアカウントも使えます。画面に通知を出す場合は、VACが案内するURLをOBSのブラウザソースに追加します。

動作環境と、起動時に必要なもの

Windows x64向け。デスクトップ画面は Microsoft Edge WebView2 Runtime を使用します。MSVCP140.dllなどの不足が表示された場合は、Microsoft Visual C++ v14 Redistributable（x64）を導入します。手順はZIPの START-HERE.txt にも収録しています。

Flowgraph Studio

イベント、条件、出力をノードでつなぐエディター。たとえば一度のチャネポ交換から、チャットへの記録と画面演出に処理を分けられます。構成を保存し、用途単位で共有・取込できます。

# VAC v2 の更新・バックアップ・復元

すでにVAC v2やそのβ版を使っている方の更新手順です。初めて使う場合は[Quickstart](./quickstart.md)、旧 `[[processors]]` 構成を変換する場合は[v1構成の移行](./v1-to-v2-migration.md)を参照してください。通常のβ版更新で、構成の変換やTwitchの再認証を最初から行う必要はありません。

## 更新する

1. 編集内容を保存し、更新する設定を使っているVACをすべて終了します。ウィンドウを閉じるだけではトレイに残るため、アプリの終了操作を使います。連携アプリの終了範囲は登録時の設定に従います。
2. 元の配布フォルダーと設定フォルダーを、別の場所へコピーします。通常の設定保存先は `%APPDATA%\UN Virtual Avatar Connect\` 全体です。`UN_VAC_CONFIG_DIR` を指定している場合はその指定先をコピーします。`profiles/` だけでなく `settings.toml` と `deleted-profiles/` も含めます。
3. `conf.toml` を指定して起動している場合は、その設定フォルダーも退避します。設定から参照するFlowgraph・辞書・素材が外部にある場合は、それらも対応する状態で残します。認証情報を含むバックアップは他人へ渡さないでください。
4. 新しいZIPを別フォルダーへすべて展開します。EXEだけの取り出しや、旧版のDLLとの混在は避けます。元と同じ保存先指定で `virtual-avatar-connect-desktop.exe` を起動します。ショートカットを使う場合は、起動先と引数を確認します。
5. 操作対象・プロファイル、ホームの動作モード、マイクの受付状態、使う接続先を確認します。保存内容を読み込めない場合は、空の構成で上書きせず、表示された診断を確認してください。

**別フォルダーへ展開しても設定は共有されます。** 試用環境を分ける場合は、設定をコピーし、試用するVACの `UN_VAC_CONFIG_DIR` にコピー先を指定します。外部参照先や実際の投稿・アプリ起動まで自動的に分離されるわけではありません。

## 元の版へ戻す

1. 対象の設定を使うVACをすべて終了します。
2. 更新後の設定・編集結果を、更新前のバックアップとは別に残します。
3. 設定フォルダーを更新前のコピーへ戻します。新旧ファイルを混ぜず、外部の辞書・構成・素材も対応する状態へ戻します。
4. 元の配布フォルダーから、元と同じ保存先指定で起動します。対象プロファイルとマイクの受付状態を確認します。

旧EXEだけへ戻すことと、設定を含めて元へ戻すことは異なります。プロファイル共有ZIPにも認証情報や編集履歴は含まれず、完全なバックアップの代わりにはなりません。復元しても、Twitchへの投稿など実行済みの外部操作は取り消されません。

この手順は保存方式に基づく案内です。すべての旧版との互換性を保証するものではなく、配布版ごとの既知の制限も確認してください。

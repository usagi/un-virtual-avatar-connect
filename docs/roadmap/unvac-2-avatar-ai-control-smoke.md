# アバター連携の確認

1. UNAvatarで検証用プロファイルのRendererを起動し、対象のアバターが表示されることを確認します。
2. VACで対象Rendererを選択し、テスト用のFlowgraphから表情・姿勢を指定します。
3. Rendererの表示で動きと中立姿勢への復帰を確認します。複数のRendererを使う場合は、選択した個体だけが反応することも確認します。
4. カメラ操作は移動前の状態を控え、効果の発動と復帰を確認します。

設定例は[アバター制御のチュートリアル](../manual/tutorials/avatar-ai-control.md)を参照してください。
